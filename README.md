# 筋トレログ 💪

スマホのホーム画面から起動できる、オフライン対応の筋トレ記録アプリ（PWA）。
サーバー不要・アカウント不要で、**記録はすべて自分の端末内**に保存されます。

## 機能

| | |
|---|---|
| 📅 **カレンダー** | 今月何回トレーニングしたか一目で確認。日付タップで過去の記録も追加 |
| 🏋️ **記録** | 94種目・部位11分類×器具5分類。重量は0.5kg刻み、推定1RMを自動計算 |
| ⏱ **休憩タイマー** | セット記録で自動スタート。10秒単位で調整、終了時にサウンド＋バイブ＋通知 |
| 🎰 **おまかせスロット** | 何をやるか決まらない日に。部位を選んでレバーを引くとメニューが決まる |
| 📈 **グラフ** | 最大重量・ボリューム・推定1RM・回数の推移 |
| 🫀 **種目詳細** | フォーム動画（開始⇄終了）＋効く筋肉を人体図でハイライト（18筋肉に細分） |
| 🕐 **セッション記録** | 開始時刻は自動、終了時刻は手動調整。日付跨ぎ対応 |

## 使い方（スマホにインストール）

### iPhone / iPad
1. **Safari** でこのページを開く
2. 共有ボタン <kbd>􀈂</kbd> → **「ホーム画面に追加」**
3. ホーム画面のアイコンから起動

> 通知を受け取るには、ホーム画面に追加したアプリから起動してください（iOS 16.4以降）。

### Android
1. Chrome でこのページを開く
2. メニュー → **「アプリをインストール」**（またはアドレスバーのインストールアイコン）

## データについて

- 記録は端末の `localStorage` に保存され、外部には一切送信されません
- 履歴タブの**エクスポート**でJSONバックアップを保存できます（機種変更時はインポートで復元）
- ブラウザのサイトデータを消すと記録も消えるため、定期的なエクスポートを推奨します
